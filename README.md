# file-taker

## Overview
A Windows utility for organizing downloaded chat attachments into structured folders.
Designed for educational and personal data-management use.

## Features
- Collects media files (images, audio, voice notes, and other attachments)
- Organizes files automatically by type
- Outputs clean, categorized directories
- Simple Windows executable

## Supported File Types
- Images (png, jpg, gif, webp)
- Audio & voice notes
- Other common attachments

## Notes
- This project does not bypass platform security.
- Intended for use with data you own or have permission to access.
- Use responsibly and in compliance with platform terms of service.

## Files
- `main.exe` — compiled Windows application
- `source code.py` — source implementation
